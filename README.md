# Student Registration Form

A basic **Student Registration Form** built using HTML to practice fundamental HTML concepts and form elements.

## 📌 About the Project

This project is a simple student registration form that collects basic student information and displays dummy student data in a table.

## 🚀 Features

- Full Name input
- Email input
- Password input
- Gender selection using radio buttons
- Skills selection using checkboxes
- Date of Birth input
- Required field validation
- Submit button
- Submitted students table with dummy data

## 🛠️ Technologies Used

- HTML5
